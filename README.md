Flasky
======

This repository contains the source code examples for the second edition of my O'Reilly book [Flask Web Development](http://www.flaskbook.com).

The commits and tags in this repository were carefully created to match the sequence in which concepts are presented in the book. Please read the section titled "How to Work with the Example Code" in the book's preface for instructions.

## Understanding Commits and Tags

Each commit and tag in this repository corresponds to a specific chapter or section in the book.

Labels such as `13a`, `17g`, etc., refer to the chapter number and subsection as presented in
*Flask Web Development*. Readers following along with the book are encouraged to check out the
appropriate tag or commit that matches the chapter they are reading.

To switch to a specific chapter or section, use:

```
git checkout <tag-name>
```

For example:

```
git checkout 13a
```
